# Calculadora

Calculadora web en español sin dependencias. Abre `index.html` en un navegador o ejecuta desde este directorio:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Incluye suma, resta, multiplicación, división, porcentaje (divide el número actual entre 100), cambio de signo y borrado. Las operaciones encadenadas se resuelven en orden de entrada. Usa los números y operadores del teclado, Enter para calcular y Escape para limpiar.
